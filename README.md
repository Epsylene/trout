# trout

![minecraft trout](img/trout.webp)

Rust implementation of [Crafting Interpreters](https://craftinginterpreters.com/), by Robert Nystrom. The repository consists of two separate projects:

1. `trout-treewalk`, for the first part of the book, implementing a simple dynamically-typed programming language with a treewalk interpreter.
2. `trout-bytecode`, for the second part, implementing a bytecode interpreter.
